# Cloudflare 测速历史与文件日志

用户已确认添加可滚动的界面历史日志和文件日志，用于排查数据源、探测及测速失败。

## 方案

复用现有 NLog，以 `[CloudflareBestIp]` 标记写入 `guiLogs/YYYY-MM-DD.txt`，遵守应用日志开关。界面记录独立于文件日志开关。相较于新增文件写入器，这能沿用已有目录和生命周期；相较于只保存进度文字，能保留被吞掉的失败原因。

每次运行创建日志分发器，将同一条带时间的日志写入文件并通过进度回调送回 UI。数据源、CIDR 回退、DNS、单个 IP 延迟与速度、达标判断、开始/完成/取消/异常均记录。保留原有探测、筛选和手动上报规则。

WPF 和 Avalonia 在结果表下方增加只读多行日志框，支持滚动和选择复制；窗口内跨次运行保留最近 1000 条，文件不受界面条数限制。界面显示文件目录及日志开关说明，不加载旧文件到 UI。

## 验证

使用模拟 HTTP 数据源验证下载失败、CIDR 回退和过滤统计日志；使用已有本地 TLS 服务验证成功结果、HTTP 503 和下载中断的日志。验证日志双路输出以及取消记录。顺序运行 ServiceLib 测试、WPF 和 Avalonia 构建，避免共享产物文件锁。
