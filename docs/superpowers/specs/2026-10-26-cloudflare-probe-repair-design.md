# Cloudflare 测速与桌面交互修复

## 已确认范围

用户要求修复评审发现的测速、筛选、导出和交互问题。除公开 Cloudflare CIDR 外，所有数据源、历史接口、上报接口均由使用者自行填写；发行代码不内置个人部署地址，已有用户配置不被覆盖。

## 实现

- 使用 .NET HTTP 协议实现解析状态码、正文长度和 chunked；通过直连指定 IP 的连接回调保留 Host/SNI，通过明文流首字节观测记录 TCP、TLS、TTFB。下载按未压缩正文和采样实际耗时计量，拒绝错误、空和意外截断响应。
- 支持 full/edge、多 SNI、分层失败率、取消和有界超时。历史与一般候选去重并过滤 CF 网段，两阶段完成后统一排名，只取合格 TOP N；取消不自动上报或导入。
- 测速独立于节点凭据。用户可仅测速；需要导入时选择已有 TLS 节点模板，或填写有效协议凭据。禁止随机生成凭据。重复导入按 IP、端口、SNI、协议和传输配置更新，记录速度与延迟。
- WPF 和 Avalonia 使用同一 ViewModel；独立测速窗口包含基本配置、数据源、导入配置和高级参数，提供输入说明、验证信息、开始/停止、明确的阶段进度与可排序结果表。
- 移除旧设置页的重复 Cloudflare 表单，菜单直接打开测速窗口。中文和英文资源共用相同键。

## 校验

使用本机 TLS/HTTP 测试服务及模拟数据源，不连接个人接口、不上报实际结果、不修改 DNS 或系统代理。回归覆盖 HTTP 失败、chunked、截断、首字节、截止时间、模式、多域名、合格筛选、全局 TOP N、取消、空数据源、公共 CIDR 兜底、凭据与幂等导入。运行现有测试、WPF/Avalonia 构建和独立窗口预览。

## 执行顺序

1. 回归测试与 HTTP 测速引擎、配置/数据源修复。
2. 两阶段全局选优、取消、结果上报与幂等导入。
3. 共享 ViewModel、两个桌面窗口与资源，移除旧表单。
4. 测试、构建、界面检查与提交。
